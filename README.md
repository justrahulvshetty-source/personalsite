# Rahul V Shetty — Personal Site

A Minecraft-themed interactive personal site.

## Flow
1. Entry — name + email capture
2. Loading — time-based greeting
3. Personal site — "MY NAME IS RAHUL V SHETTY..."
4. Want to play? — door video → 5-question quiz → 10% Cave coupon
5. Villager contact (LinkedIn + Email)

## Stack
- Single `index.html` (no build step)
- Supabase (response storage)
- GoatCounter (analytics)
- Cloudflare Pages (hosting)

## Files
- `index.html` — the site
- `bg.gif` — animated background
- `door.mp4` — door-opening transition
- `music.mp3` — background music
- `favicon.ico`, `favicon-32.png` — icons
- `og.jpg` — social share preview
